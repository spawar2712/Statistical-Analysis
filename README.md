# Statistical-Analysis
📌 Project Overview
This project focuses on Statistical Analysis of Data using Python.
The main objective is to understand the dataset, perform statistical calculations, identify patterns, and derive meaningful insights from the data.

🛠️ Technologies Used
Python
Pandas
NumPy
Matplotlib
Seaborn
Jupyter Notebook

📊 Statistical Analysis Performed
The project includes the following statistical techniques:
Mean
Median
Mode
Minimum and Maximum
Range
Variance
Standard Deviation
Quartiles
Percentiles
Interquartile Range (IQR)
Skewness
Kurtosis
Correlation
Outlier Detection

🔍 Project Workflow
Import the required Python libraries
Load the dataset
Understand the structure of the data
Perform data cleaning
Perform descriptive statistical analysis
Identify outliers
Analyze data distribution
Calculate correlation between variables
Create visualizations
Generate meaningful insights

📈 Visualization
The project uses different charts to understand the data:
Histogram
Box Plot
Bar Chart
Scatter Plot
Heatmap

🎯 Key Objectives
Understand the distribution of data
Identify central tendency and variability
Detect unusual values and outliers
Understand relationships between variables
Generate useful business/data insights

🚀 How to Run the Project
1. Clone the Repository
git clone https://github.com/spawar2712/Statistical-Analysis.git
2. Navigate to the Project Folder
cd Statistical-Analysis
3. Install Required Libraries
pip install pandas numpy matplotlib seaborn jupyter
4. Open Jupyter Notebook
jupyter notebook

Open the Statistical_Analysis.ipynb file and run the cells.
